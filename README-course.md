# 智慧树桌面助手 0.2.1 Beta2 · 自动看课＋自动答题

默认入口“开始看课＋答题”：展开目录 → 正常播放未完成视频 → 回答视频弹题 →
核对当前课时完成标记 → 切换下一节 → 完成章节作业并提交 → 返回课程 → 结束复扫。
本版按最初截图的智慧树共享课视频页开发；真实平台验证状态见 TEST-REPORT.md。

## 直接运行

完整解压 Windows x64 包，运行 `AutovisorDesktop.exe`。保留 `_internal` 文件夹。
无需安装 Python 或浏览器扩展；OCR 模型已随包提供。

## 新版变化

默认自动静音课程标签页，已静音不会反向开启声音。AI 设置页新增就地测试状态、耗时、取消与重试；保存密钥不等于已验证连接。详见 TEST-REPORT.md。

## 一次性设置

1. 在 Edge 手动登录智慧树，打开课程，主屏幕最大化，浏览器缩放设为 100%。
2. 运行模式保持“看课＋答题（整门课程）”，填写页面实际显示的课程名称并绑定窗口。
3. 分别校准四个区域：视频画面及控制条、右侧完整课时目录、视频弹题、章节题目。
   视频弹题可先框选整个视频内容区；章节题目需先打开作业页校准，包含题型、题号和全部输入控件，再返回课程。
   目录需包含章节、课时名称、时长和右侧完成标记；程序会自动展开章节。
4. 每次校准有 3 秒切回目标窗口，拖动框选后 Enter 保存，Esc 取消。窗口尺寸变化需重新校准。
5. 在“AI 设置”本地填写 DeepSeek API Key 并保存，官方接口和 `deepseek-flash` 已预设。
   可用“发送测试题验证接口”检查调用。密钥进入 Windows 凭据管理器，普通配置不保存密钥。
6. 回到课程页点击“开始看课＋答题”。程序会尝试激活目标窗口；必要时按提示手动切回。

视频播放本身不需要密钥；遇题没有可用密钥会暂停。要全程自动完成弹题和章测，应先配置密钥。
DeepSeek 网页账号不能代替 API Key，接口按你的开放平台账户计费：<https://platform.deepseek.com/>。

## 整课运行

- 正常速度播放、不设时长上限，不修改学时，不调用平台私有进度接口。
- 同名课时按章节和数字编号分别记录；已完成资源按平台标记跳过。
- 从当前未完成课时或持久记录继续；视频到末尾后还要等当前这一节的完成标记。
- 平台 60 秒未确认本节完成，或续播检查后仍持续无进展，会暂停说明原因。
- 视频弹题支持文字单选、多选、判断和多空填空，填写复核并确认后继续原视频。
- 本章视频完成后自动进入章测，答完全部题目、检查漏题、提交并确认结果，再返回课程。
- 提交状态不明时不盲目重交；结果章节不一致、返回课程失败时暂停。
- 最后重新完整扫描目录，确认入库视频与章测均完成后才显示“整门课程完成”。

## 暂停、恢复与停止

- `Ctrl+Alt+Shift+F12` 全局停止；鼠标移至主屏幕角落或点击停止按钮也可停止。
- “暂停”停止脚本动作，网页视频可能仍继续播放；恢复后以页面实际进度为准。
- 重启后绑定同一课程、使用原课程名称和校准数据，程序按记录及真实目录状态恢复。
- 失焦、切到其他网站、窗口尺寸变化、验证码、异常脚本提示或不可靠识别会暂停。
- 既有完成记录不当作本次程序取得的成绩。课程批次变化或记录冲突时先核对平台状态，
  再清除本地运行记录重建任务；清除记录不会修改平台数据。

## 一键整课离线演示

默认模式点击“离线演示”，自动运行两章、四段普通计时视频、四种弹题及两份含多空题的章测。
演示自动绑定和校准，不需要密钥。使用固定答案和本地计时，不访问智慧树或在线 AI。
演示时保持演示窗口在前台。“仅答题”模式保留旧的四题演示。

## 范围与数据

支持普通视频及带题号、总题数、下一题按钮的单题作业面板。
整卷多题、新版模板、文档阅读、直播、讨论、复杂公式编辑器和正式考试需另行处理。
需要窗口持续可见，同一时间只运行一个自动化任务。

配置、日志、课程及作答记录位于 `%LOCALAPPDATA%\AutovisorDesktop`。
课程任务和题目记录分别保存；AI 只接收题干和选项文字，默认不上传截图。
本程序不保证 AI 全部答对或平台不会检测到自动化。
