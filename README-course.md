# 智慧树桌面助手 0.3.0 Beta1 使用说明

## AI 看图模式

绑定课程窗口、填写真实课程名称、配置自己的 DeepSeek Key 后即可开始，不必先框选四区。
AI 直接读取截图，判断目录、未完成课时、声音、播放、题目、弹题结果和作业结果。
同一稳定题面最多批量执行四个选项或填空，之后重新截图；导航、滚动和提交单独处理。

## 首次设置

1. 完整解压 Windows 包，运行 `AutovisorDesktop.exe`，保留 `_internal`。
2. 手动登录智慧树，将 Edge/Chrome 放在主屏幕并设缩放 100%。
3. 运行页填写画面上的真实课程名称，刷新并绑定正确窗口。
4. 保持“AI 看图（自动定位）”；AI 设置填写接口、模型与 Key。
5. 点击“测试连接”，等待本页显示图片接口、识题和位置验证成功，再保存配置。
6. 点“开始看课＋答题”，在倒计时内切回课程窗口并保持前台。

图片测试只验证当前输入，更改 Key、模型、接口或控制方式后需要重新测试。
测试中可取消；失败会显示 Key、余额、模型权限、图片支持、网络或超时等原因，支持重试。
仅保存 Key 不代表连接可用。不要把 Key 发到聊天或分享给别人。

## 运行与恢复

- 默认自动静音，已静音不反向开启声音。
- 目录从顶部到末尾扫描，合并重叠条目，当前未完成课时优先续播，之后按目录补漏。
- 只有当前视频结束并确认它自己的完成标记后才切课。
- 本章视频完成后做章节作业，检查题号、复核填写后提交；确认结果并返回课程。
- 全部任务结束后还会再次全量复扫，才能显示整门课程完成。
- 保留 SQLite 记录可恢复。提交状态不明确时不会盲目重交。
- 运行页显示 AI 当前判断、操作、请求次数、tokens 及最近请求耗时。停止后的迟到回复不再执行。

暂停、继续和停止按钮保留；`Ctrl+Alt+Shift+F12` 或鼠标移至主屏幕角落可紧急停止。
失焦、布局变化、验证码、异常脚本提示、正式考试或无法可靠识别会暂停。
停止后仍等待网络请求时，先等旧任务退出，再开始新任务。

## 人工修正与旧模式

暂停后可在区域校准页框选相应区域，作为 AI 定位提示和操作范围限制，然后继续。
“恢复 AI 自动定位”可以清除人工修正。“识别预览”为只读，不点击、不填写。

需要旧路线时，切换“本地 OCR（旧版）”。旧版整课模式仍需视频、目录、视频弹题、章节题目四区校准。
切换不会清除 Key 或学习记录；交卷状态不明确时不要换模式重交。

## 数据与范围

Key 位于 Windows 凭据管理器，配置与学习记录位于 `%LOCALAPPDATA%\AutovisorDesktop`。
看图模式会发送绑定课程窗口截图和任务上下文给 AI 服务。原始截图默认不保存；显式启用 `--capture-test-samples` 才写入本地测试目录。
分享程序不要附带自己的配置、数据库或原始日志。

离线演示使用固定演示状态验证执行，不调用在线 AI；真实图片测试与平台验收以 TEST-REPORT.md 为准。
源码与测试命令见 README.md。仅支持传统智慧树共享课与单题作业，正式考试、图片作答、复杂公式、直播、讨论和其他平台需另行适配。
AI 可能答错或误判，不保证全部正确或平台免检测。MIT 来源与改造范围见 LICENSE 和 UPSTREAM.md。
